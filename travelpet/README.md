# 여행펫 (TravelPet)

내 띠 펫과 함께 떠나는 여행 앱. `index.html`을 열면 바로 실행돼요 (빌드 필요 없음).

## 화면
- **회원가입**: 생년월일을 넣으면 띠가 자동으로 정해져요. 설날(음력 1월 1일) 전에 태어났으면 전 해의 띠로 계산해요. 펫 색 고르기, 이름 짓기.
- **홈(가운데 펫 버튼)**: 펫이 화면을 채우는 방. 먹이주기 · 놀아주기 · 펫 꾸미기(색상/모자/안경/목/소품) · 방 꾸미기(가구/벽지/바닥, 끌어서 배치).
  처음엔 빈 방에서 시작하고, 여행 기록으로 받은 코인으로 꾸밀수록 화려해져요. 레벨이 3·6·9가 되면 반짝이·오라·링이 생겨요.
- **여행계획**: 실제 지도 위에 일차별 일정, 장소 검색, 동행 초대 링크.
- **항공·명소**: 항공권 조건을 네이버 항공권/구글 항공편/스카이스캐너로 넘겨서 검색, 가볼만한 곳 지도.
- **여행지도**: 국내 시·군·구 229곳, 해외 나라 → 주·도·현 단위로 색칠. 색칠된 지역을 누르면 기록을 보고 남길 수 있어요.
- **12간지**: 12가지 펫 도감.

## 구글 지도 켜기
홈 오른쪽 위 ⚙️ 설정 → 구글 지도 API 키 입력.
Google Cloud에서 **Maps JavaScript API**와 **Places API (New)**를 켜고, 키는 HTTP 리퍼러로 내 사이트 주소만 허용해 두세요.
키가 없으면 OpenStreetMap 지도와 검색을 써요.

## 알아둘 점
- 데이터는 브라우저(localStorage)에만 저장돼요. 동행 초대는 여행 계획을 링크에 담아 주고받는 방식이라, 실시간 동시 편집을 하려면 서버(예: Firebase)가 필요해요.
- 지도 경계 데이터: 국내는 행정동 경계(vuski/admdongkor, 2025-10 기준)를 시·군·구로 합침, 해외는 Natural Earth admin-1.
